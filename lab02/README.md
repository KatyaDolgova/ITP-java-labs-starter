## Инварианты `DataSample`

Для любого корректно созданного объекта `DataSample` всегда истинно:

1. `id` не равен `null` и не пустая строка.
2. `label` не равен `null` и не пустая строка.
3. `status` не равен `null`.
4. `features` не равен `null` и содержит хотя бы один элемент.
5. Каждое значение в `features` - конечное число (не `NaN` и не `Infinity`).
6. После создания объекта `id` (поле `final`); изменить его напрямую снаружи невозможно.
7. `status` можно изменить только через метод `changeStatus(SampleStatus newStatus)`, который сам не допускает `null`.
8. Метод `getFeatures()` возвращает копию внутреннего массива, а не ссылку на него - изменение возвращённого массива не влияет на состояние объекта, и наоборот, изменение массива, переданного в конструктор, после создания объекта не влияет на объект.
